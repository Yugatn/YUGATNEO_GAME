# YUGATNEO CHESS

Адаптивная веб-игра в шахматы для двух игроков на одном устройстве. Интерфейс на русском языке, минималистичная тёмно-зелёная тема.

## Возможности

- Полная легальность ходов на основе chess.js: шах, мат, пат, рокировка, взятие на проходе, превращение пешки и ничьи.
- Поочерёдная игра вдвоём на одном устройстве.
- Подсветка выбранной фигуры, возможных ходов и последнего хода.
- История ходов в шахматной нотации, отмена хода, переворот доски.
- Часы для блица и рапида: 3, 5, 10 и 15 минут; автоматическое завершение при истечении времени.
- Режим игры против компьютера с тремя уровнями сложности. Локальный ИИ использует minimax с альфа-бета-отсечением и оценкой материала/позиции; для сетевой игры не требуется.
- Возможность играть вдвоём на одном устройстве или против ИИ (человек играет белыми).
- Настраиваемые имена игроков.
- Автоматическое сохранение партии, имён и оставшегося времени в локальном хранилище браузера; восстановление после перезагрузки.
- Экспорт партии в PGN через копирование.
- Адаптация к мобильным экранам и установка как мини-приложение в поддерживаемых браузерах.
- Service worker кэширует оболочку и шахматный движок для последующего запуска офлайн после успешной загрузки.

## Публикация и запуск

Для публикации через GitHub Actions:

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **GitHub Actions** как источник публикации.
3. Сохраните настройки. Workflow из `.github/workflows/pages.yml` соберёт и опубликует сайт после push в `main`.
4. Откройте `https://yugatn.github.io/YUGATNEO_GAME/`. Первый запуск workflow может занять несколько минут; его состояние видно во вкладке **Actions**.

Для локального запуска используйте HTTP-сервер в корне проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

> Для первого запуска необходим интернет, чтобы загрузить библиотеку chess.js с CDN. После успешного кэширования сервис-воркером приложение может запускаться без сети. Для установки как PWA нужен HTTPS (GitHub Pages его поддерживает).

## Управление

1. Нажмите на свою фигуру.
2. Выберите подсвеченную клетку.
3. Передайте устройство сопернику.
4. Используйте «Отменить ход», чтобы отменить последний ход, или «Новая партия», чтобы начать заново.

## Структура

- `index.html` — интерфейс, стили и игровая логика.
- `manifest.json` — метаданные устанавливаемого приложения.
- `sw.js` — кэширование оболочки и движка для офлайн-запуска.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages.

## Технологии

HTML, CSS, JavaScript, chess.js 0.10.3. Без сборки и серверной части. Партия хранится в памяти вкладки; онлайн-мультиплеер между разными устройствами не реализован.
