# YUGATNEO GAME — CHESS и MATRIX RUNNER

## СИМБИОНТ · Город решений — развивающая игра для всех возрастов

**[Открыть игру](https://yugatn.github.io/YUGATNEO_GAME/symbiont-city/)** · **[Исходники](symbiont-city/)** · **[Возрастная методология и инструкция](symbiont-city/README.md)**

Новая самостоятельная обучающая Telegram Mini App для вселенной «Сюжет Икс». **Обновление v3:** три реальные игровые мастерские — пары по памяти, зрительный поиск символов и пошаговое строительство моста. Завершая их, игрок восстанавливает три новых объекта города, а результаты сохраняются на устройстве без регистрации.  Семь районов и 14 исходных интерактивных миссий дополнены **Лабораторией решений**: 5 сюжетных ситуаций о сотрудничестве, эмоциях, проверке информации и ограниченных ресурсах. Действия меняют четыре условных показателя города, а решения можно пересматривать без накопления фиктивных наград. Игрок исследует карту города, выполняет практические задания, обсуждает результаты и восстанавливает районы. **Возрастные профили от 0 до 110 лет:** для 0–2 только рекомендации взрослым по офлайн-общению; 3–5 совместные короткие задания; отдельная адаптация каждого года 6–17; взрослые и старшие возрастные сценарии. Сложность можно менять независимо от возраста. Локальное сохранение, без чата, рекламы и регистрации. Результаты — только игровая мотивация, не психологическая диагностика.

## ЛАБИРИНТ ИКС · большая многоярусная Telegram Mini App

**[Открыть после публикации](https://yugatn.github.io/YUGATNEO_GAME/maze-x/)** · **[Исходники](maze-x/)** · **[Концепция и инструкция](maze-x/README.md)**

Новая развивающая игра «Сюжета Икс» с **большими процедурными лабиринтами 25×25, 37×37, 49×49 и 65×65** на 2–5 спиральных этажах. Камера следует за бегущим человеком в круглых очках и показывает только ближайшие коридоры. Агенты преследуют по настоящим проходам; порталы переключают мир на матричный код и дают возможность фазового прыжка через стену. На развилках встречаются **логические загадки**: правильный ответ даёт бонус и подсветку части кратчайшего пути, неправильный не раскрывает маршрут, пропуск — без штрафа. Добавлена **карта памяти только изученных коридоров**, останавливающая игровое время. Исследовательские очки теперь выдаются только за первое посещение клетки; устранены повторные награды за бег туда-обратно и частое уклонение от агента. Остаются бонусы за порталы, загадки и скорость прохождения, а также локальное сохранение с переносом старых результатов. Без сервера, без токенов, доступна через BotFather после публикации HTTPS. Остальные игры сохранены.

## EVOLUTION X · клетка → человек → Матрица → ракета → новая планета

**[Запустить после публикации](https://yugatn.github.io/YUGATNEO_GAME/evolution-x/)** · **[Исходники](evolution-x/)** · **[Полная концепция и инструкция](evolution-x/README.md)**

Отдельная Telegram Mini App в мире «Сюжета Икс». Игрок вручную делит исходную клетку на две и затем **каждую клетку поколения**, пока их не станет 256 (255 касаний). После анимированного перехода появляется бегущий человек в круглых очках: обход препятствий, прыжки, матричные порталы, щит и энергетический импульс. Далее — ракета, уклонение от астероидов, посадка на новую планету и **повторение цикла развития**. Счёт и прогресс сохраняются локально. Это художественная метафора, не биологическая модель развития.

HTML5 Canvas без графических зависимостей; управление касаниями в Telegram и в обычном браузере. Запуск внутри Telegram требует регистрации HTTPS-адреса Mini App у владельца бота в **@BotFather**. Тесты: `tests/evolution-x.test.cjs`, GitHub Actions `evolution-x-ci.yml`. Другие игры репозитория не заменяются.

## SPIRAL RUN · Telegram Mini App / вид сверху

**[Играть в SPIRAL RUN после публикации](https://yugatn.github.io/YUGATNEO_GAME/matrix-sprint/)** · **[Код новой игры](matrix-sprint/)** · **[Инструкция запуска в Telegram](matrix-sprint/README.md)**

Новая мини-игра в измерении «Сюжета Икс»: вид сверху и переключение камеры сзади, бегущий персонаж в круглых солнцезащитных очках, касания слева/справа для смены полосы и поворотов, центр для прыжка. На маршруте появляются препятствия, подъёмы на новые уровни и портал; после прыжка в портал пространство преобразуется в матричный код, появляются агенты и заряжаемый энергетический импульс. Очки за расстояние, препятствия, уклонения и открытия.

Работает как отдельная браузерная HTTPS-игра; благодаря официальному `telegram-web-app.js` может быть зарегистрирована в **@BotFather** как Mini App или кнопка меню бота. **Публикация GitHub Pages и настройка вашего бота — разные этапы**; пока сайт не опубликован, прямой Telegram-запуск не подтверждён. Для игрового ядра предусмотрены проверки Node.js и CI. Старый проверенный боковой `/runner/` сохранён без изменений.

## MATRIX RUNNER · мини-игра

**[Играть онлайн](https://yugatn.github.io/YUGATNEO_GAME/runner/)** · [Исходники](runner/) · [Игровое ядро](runner/engine.js)

Отдельная оригинальная браузерная игра на Canvas 2D: чёрный фон и белые линии,
бегущий человечек, препятствия, воздушные порталы. После попадания в портал
на 8 секунд появляется матричный код и усиливается прыжок; доступен один
дополнительный прыжок в воздухе. Данные аккаунта Telegram не требуются.

**Управление:** пробел, ↑, W или касание игрового поля / кнопки «Прыжок».
Есть пауза и перезапуск; скрытие вкладки автоматически останавливает игру.
Личный рекорд (только числовое значение) сохраняется в localStorage,
прочих персональных данных игра не запрашивает. Встроен автономный service worker
для повторного офлайн-запуска после успешного первого открытия.

**Telegram:** отправьте в чат ссылку
`https://yugatn.github.io/YUGATNEO_GAME/runner/` и откройте её во
встроенном браузере Telegram. Это обычная HTTPS-веб-игра.
Для запуска как **Telegram Mini App через кнопку бота** отдельно настройте
бота и его Mini App в BotFather, указав этот HTTPS-адрес. Самостоятельно
создать бота или привязать приложение без данных владельца бота нельзя.

**Проверка:** `node tests/runner-engine.test.cjs`.
Проект не копирует код или графику Google Dino.

## CHESS · шахматы

Адаптивная веб-игра в шахматы для двух игроков на одном устройстве. Интерфейс на русском языке, минималистичная тёмно-зелёная тема.

## Возможности

- Полная легальность ходов на основе chess.js: шах, мат, пат, рокировка, взятие на проходе, превращение пешки и ничьи.
- Поочерёдная игра вдвоём на одном устройстве.
- Подсветка выбранной фигуры, возможных ходов и последнего хода.
- История ходов в шахматной нотации, отмена хода, переворот доски.
- Часы для блица и рапида: 3, 5, 10 и 15 минут; автоматическое завершение при истечении времени.
- Режим игры против компьютера с тремя уровнями сложности. Локальный ИИ использует minimax с альфа-бета-отсечением и оценкой материала/позиции; для сетевой игры не требуется.
- Возможность играть вдвоём на одном устройстве или против ИИ (человек играет белыми).
- Настраиваемые имена игроков.
- Автоматическое сохранение партии, имён и оставшегося времени в локальном хранилище браузера; восстановление после перезагрузки.
- Экспорт партии в PGN через копирование.
- Адаптация к мобильным экранам и установка как мини-приложение в поддерживаемых браузерах.
- Service worker кэширует оболочку и шахматный движок для последующего запуска офлайн после успешной загрузки.

## Публикация и запуск

Для публикации через GitHub Actions:

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **GitHub Actions** как источник публикации.
3. Сохраните настройки. Workflow из `.github/workflows/pages.yml` соберёт и опубликует сайт после push в `main`.
4. Откройте `https://yugatn.github.io/YUGATNEO_GAME/`. Первый запуск workflow может занять несколько минут; его состояние видно во вкладке **Actions**.

Для локального запуска используйте HTTP-сервер в корне проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

> Для первого запуска необходим интернет, чтобы загрузить библиотеку chess.js с CDN. После успешного кэширования сервис-воркером приложение может запускаться без сети. Для установки как PWA нужен HTTPS (GitHub Pages его поддерживает).

## Управление

1. Нажмите на свою фигуру.
2. Выберите подсвеченную клетку.
3. Передайте устройство сопернику.
4. Используйте «Отменить ход», чтобы отменить последний ход, или «Новая партия», чтобы начать заново.

## Структура

- `index.html` — интерфейс, стили и игровая логика.
- `manifest.json` — метаданные устанавливаемого приложения.
- `sw.js` — кэширование оболочки и движка для офлайн-запуска.
- `.github/workflows/pages.yml` — автоматическая публикация на GitHub Pages.

## Технологии

HTML, CSS, JavaScript, chess.js 0.10.3. Без сборки и серверной части. Партия хранится в памяти вкладки; онлайн-мультиплеер между разными устройствами не реализован.
