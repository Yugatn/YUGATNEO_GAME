# YUGATNEO MATRIX RUNNER X — Telegram Mini App

**Авторский мир:** «Сюжет Икс» Югатна. **Тип:** самостоятельная мини-игра, совместимая с браузером и Telegram Mini Apps. **Технологии:** HTML5, Canvas 2D с программной 3D-проекцией, JavaScript, service worker, Telegram WebApp API без обязательной регистрации.

## Идея

Наблюдатель в круглых солнцезащитных очках бежит по спиральной дороге сквозь последовательность виртуальных измерений. Трасса не просто прямая полоса: она делает повороты в пространстве и поднимается по уровням. В одном из витков появляется портал. Прыжок в кольцо переключает окружающий мир в цифровое пространство из зелёных символов и временно открывает защитный энергетический импульс. Время от времени позади появляются фантастические агенты-преследователи — их можно обойти прыжком или обезвредить импульсом. В качестве учебного игрового опыта задействуются реакция, ориентирование, предвосхищение и переключение внимания, **но это не медицински подтверждённая методика развития интеллекта или диагностика реакции**.

Персонаж, портал, трасса, преследователи и эффекты рисуются оригинальным кодом, без копирования графики, музыки, персонажей и исходников художественных фильмов или Google Dino.

## Управление

- Тап по **центру игрового полотна** → прыжок.
- Тап по **левому / правому краю** → смена полосы. В зоне развилки такой тап **запоминает команду соответствующего поворота**. Ошибка или пропуск направления завершает забег; перед поворотом появляется текстовое предупреждение.
- Физические кнопки снизу доступны одновременно с жестами — для удобства и доступности.
- **⚡ ИМПУЛЬС** появляется после прохождения воздушного портала, работает по окружающим агентам, имеет перезарядку.
- **◉ ВИД СЗАДИ / ВИД СВЕРХУ** переключает верхний/третьеличный ракурс. Камера плавно разворачивается при смене направления движения.
- Пауза всегда доступна. Если Telegram свернут или вкладка скрыта, игра останавливается без штрафов.
- На компьютере: пробел / W / ↑ — прыжок, A / ← и D / → — управление, F — импульс, V — камера, P — пауза, Enter — старт.

## Очки

`score = floor(distance * 2) + bonuses`.

Бонусы: +30 за каждый успешно пройденный объект, +75 за правильный пространственный поворот, +160 за подъём на новую платформу, +220 за воздушный портал, +110 за агента, обезвреженного импульсом, +45 за агента, обойдённого прыжком. Скорость постепенно возрастает в ограниченных пределах. Личный рекорд — **одно число в localStorage**, без пользовательских профилей, аккаунтов, геолокации и передачи результатов на внешние серверы. Онлайн-рейтинг не реализован.

## Архитектура файлов

```text
runner-x/
  index.html            адаптивный экран, заставка и элементы управления
  engine.js             детерминированная логика препятствий, прыжков, поворотов и очков
  render.js             2.5D/3D-проекция трассы, верхний и задний ракурсы, пиксельный код
  app.js                игровой цикл, сенсорное управление, клавиатура, Telegram WebApp SDK
  icon.svg              оригинальный символ персонажа в круглых очках
  manifest.webmanifest  параметры автономного веб-приложения
  sw.js                 кеширование только файлов игры, не Telegram-профиля

tests/runner-x.test.cjs  автоматические проверки правил игры в Node.js
```

В редакции MVP отсутствуют: аккаунтные таблицы лидеров, покупки, платный функционал, сбор имён/профилей Telegram, многопользовательский режим, боты Telegram API и внешний игровой сервер.

## Проверка локально

```bash
node tests/runner-x.test.cjs
python3 -m http.server 8000
```

Открыть `http://localhost:8000/runner-x/` в браузере. Открыть DevTools и убедиться в отсутствии ошибок JavaScript; проверить портретное мобильное разрешение (например, 393×852), сенсорные края, центр, две камеры, паузу, портал и импульс. Тестируйте на реальном телефоне дополнительно — эмулятор не гарантирует одинаковый отклик пальцев.

## Публикация и запуск в Telegram

При размещении на GitHub Pages после объединения ветки с `main`, целевой HTTPS-адрес:

`https://yugatn.github.io/YUGATNEO_GAME/runner-x/`

**Только после проверки действительной доступности адреса используйте его в настройках бота.** Публикация репозитория не равнозначна регистрации Mini App в Telegram.

1. Откройте [@BotFather](https://t.me/BotFather) в своём Telegram под аккаунтом владельца бота.
2. Выберите `/mybots` → нужного бота → **Bot Settings → Configure Mini App** для основной кнопки приложения (или **Menu Button** / `/setmenubutton` для кнопки меню).
3. Укажите HTTPS-адрес страницы `runner-x/`; подпись, например, `🎮 MATRIX RUNNER X`.
4. Сохраните настройку в BotFather и откройте бота в Telegram. Убедитесь, что кнопка открывает игру **в Telegram**, а не только обычный браузер.
5. Проверьте iOS/Android, безопасные области экрана, поворот камеры, таймеры и работу фоновой паузы.

На стороне игры подключён официальный `<script src="https://telegram.org/js/telegram-web-app.js">` и при наличии WebApp вызываются `ready()`, `expand()`, `setHeaderColor()`, `setBackgroundColor()`, `disableVerticalSwipes()` и необязательная тактильная отдача. Вне Telegram всё продолжает работать как обычный веб-раннер. Для этого режима **не нужно передавать токен бота в HTML/JavaScript**. Если в дальнейшем появится серверное сохранение счёта, Telegram `initData` надо валидировать на сервере, никогда не доверять `initDataUnsafe` в клиентском коде.

Документация Telegram: <https://core.telegram.org/bots/webapps>.

## Критерии готовности / проценты

- Разработаны исходники игры, управление, матричный портал, суперспособность, повороты, камеры, агенты и заставка — **10 / 14 критериев**.
- Локальные тесты игрового ядра и тестирование сенсорного интерфейса в Chromium — ещё **2 / 14**.
- Реальная публикация GitHub Pages по HTTPS — **1 / 14**, подтвердить после деплоя.
- Привязка к **конкретному боту** и тест в настоящем Telegram на устройстве владельца — **1 / 14**, требует действий владельца в BotFather.

До реальных тестов нельзя называть продукт публично проверенным Telegram Mini App. Следующие этапы — фоновые декорации, дополнительные типы препятствий, режим тренировки без выбывания, безопасная локальная статистика с добровольным сбросом, улучшение доступности.
