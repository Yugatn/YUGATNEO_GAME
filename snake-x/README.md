# ЗМЕЙКА × ОКЕАН

Полностью переработанная версия игрового прототипа «Крыши → Океан»: теперь это цельная **Snake-аркада** на квадратном поле 22×22 с 2 игровыми режимами.

## Играть

- GitHub Pages: `https://yugatn.github.io/YUGATNEO_GAME/snake-x/`
- Старый адрес игры (после перенаправления): `https://yugatn.github.io/YUGATNEO_GAME/roof-to-ocean/`
- Локально: откройте `index.html` в браузере. Никакого сервера и сборки не требуется.

## Режимы

- **Путешествие** — семь последовательных уровней: девятиэтажка, крыши, улицы, полёт, мотоцикл, океан, пляж. Сюжет передан как сменяющиеся темы **одной и той же механики Snake**. На каждом уровне нужно собрать от 4 до 7 фруктов. Препятствия стилизованы под окружение. За прохождение каждого этапа доступен следующий. При трёх столкновениях путешествие начинается заново. В финале — змейка на шезлонге.
- **Классика** — бесконечный рост, ускорение, рекорд, нет препятствий и дополнительных жизней.

## Портал

В некоторых этапах Путешествия появляется матричный портал. Соприкосновение на 8 секунд даёт ускорение, удвоенные очки и возможность проходить сквозь стены и препятствия (в том числе собственное тело). Находясь в состоянии фазы, змейка появляется на противоположной стороне поля при выходе за границу.

## Управление

- Стрелки или `W` `A` `S` `D` — поворот.
- `Пробел` / `P` — пауза и продолжение.
- `Enter` — начало игры или следующий этап.
- `R` — начать заново.
- Телефон — свайп по игровому полю либо кнопки направления под ним.

Записи рекорда и достигнутого этапа остаются только в `localStorage` текущего браузера. Звук включается отдельно, по желанию. При сворачивании вкладки игра автоматически ставится на паузу.

## Технически

Один HTML-файл со встроенными CSS и JavaScript; Canvas 2D; фиксированная логическая сетка 22×22; пиксельная отрисовка по размеру контейнера с учётом DPR; игровой цикл requestAnimationFrame с фиксированным шагом; пассивные анимации, не влияющие на физику.

Исходный код предыдущей платформенной версии сохраняется в истории коммитов GitHub. Никаких персональных данных игра не запрашивает и не отправляет.
