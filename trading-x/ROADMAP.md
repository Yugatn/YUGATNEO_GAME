# Trading X — дорожная карта

Автор проекта: Югатн. Версия 0.1, 28 ноября 2026 года.

## Цель
Обучающий биржевой квест: чтение OHLCV, вероятностное мышление, риск и понимание экономики. Никаких реальных ордеров, депозитов и обещаний доходности. XP за освоение знаний, а не за торговый оборот или прибыль.

## Реализовано в 0.1
- [x] Десять учебных квестов: свечи, тренды, диапазон и уровни, EMA, RSI, Stochastic, MACD, фундаментальные факторы, лимит риска.
- [x] Свечной/линейный график, 15m/1H/4H из одного 15m ряда, масштаб, OHLC по нажатию, объём, EMA 12/26, ATR14 (простое среднее TR), RSI, Stochastic %K14/%D3, MACD 12/26/9.
- [x] Отдельный симулятор с четырьмя рыночными режимами, 10 000 у.е., раскрытием будущих свечей по шагам, LONG/SHORT, стопом, целью и ручным закрытием.
- [x] Плановый риск 0,25–1% закрытого капитала, лимит номинала, допущения о комиссии и проскальзывании; при неоднозначности OHLC — приоритет стопа.
- [x] XP, звания и локальное сохранение прогресса кампании; журнал текущего сценария.
- [x] Ссылка из общего меню игр.
- [x] 19 проверок вычислительного ядра при создании; проверка синтаксиса JS.
- [ ] Визуальная проверка в реальных браузерах iOS/Android/desktop и подтверждение публикации Pages.

## 0.2 — лаборатория графиков
- [ ] Конструктор свечей OHLC с проверкой допустимости; молот, доджи, поглощение, ложные пробои.
- [ ] Задания на самостоятельную разметку поддержки, сопротивления и трендовых линий; сравнение с эталонными зонами.
- [ ] Параметры индикаторов, MACD-гистограмма, Bollinger Bands, Wilder ATR; предупреждения о недостаточной истории.
- [ ] Кроссхейр, жесты масштабирования, панорамирование, временная ось, полноэкранный график.
- [ ] Улучшение доступности, компактный мобильный режим, графический и звуковой feedback с отключением.

## 0.3 — экономика и инвестиции
- [ ] Квесты по спросу и предложению, ставке, инфляции, отчётности, ожиданиям, дивидендам, долговой нагрузке и мультипликаторам.
- [ ] Сценарии цепочек поставок: дефицит сырья, изменение спроса, шок производства, новости и контрсценарии; эффект не детерминирован.
- [ ] Виртуальный портфель разных активов, корреляция, диверсификация, ликвидность и концентрация.
- [ ] Сравнение инвестирования, активного трейдинга и отсутствия сделок с учетом затрат.

## 0.4 — исследовательская академия CryptoSimbiont
- [ ] Исторический replay с лицензированными или доступными для переиспользования данными, контроль качества, отсутствие look-ahead.
- [ ] Раздельные train/validation/test, walk-forward; тестирование EMA и других гипотез.
- [ ] Mark-to-market equity и просадка, expectancy, profit factor, win rate, стресс-тест затрат; выгрузка журнала.
- [ ] Отдельный учебный модуль funding, спреда, плеча, маржин-колла, гэпов, частичных исполнений, неопределённости.
- [ ] Тесты расчётов, UI/E2E и регрессии; сценарий потери капитала не должен мотивировать отыгрываться.

## Ограничения 0.1
Данные полностью синтетические; уровни — экстремумы окна, не полноценные зоны; фазы рынка заданы генератором. Симулятор не сохраняет капитал при переключении режимов. Просадка только по реализованным результатам. Нет funding, ликвидаций, частичного исполнения, налогов и реальной рыночной ликвидности. Никакая учебная стратегия не подтверждена независимым бэктестом.
