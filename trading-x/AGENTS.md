## Карта кода (0.4.5)
- index.html: автономная HTML/CSS/JS страница; все стили и скрипты локальные. Первый script — диагностика запуска; второй — игровое ядро и UI.
- E — генератор рынка, агрегация OHLCV, SMA/EMA/RSI/Stochastic/MACD/ATR, модель исполнения. Данные синтетические, future bars скрыты посредством cursor.
- Q и lessons — параллельные массивы викторин и объяснений. Длины должны совпадать. lessonIds — неизменяемые строковые ID по индексу Q; courseChapters, courseOrder и courseMeta задают главы и уровни независимо от Q. Новые задания добавлять в конец Q/lessons/lessonIds и ровно в одну главу. Старые индексы сохранять для обратной совместимости.
- render(), visible(), context(), line() — отрисовка графиков; drawMeta.a — видимое окно, left/step — координаты выбора; selection — t выбранной свечи. Индикаторы рассчитывать по всей доступной истории, а не только видимому окну. Метки выбранной свечи синхронизировать.
- practiceTasks — стабильные строковые ID, type quiz/pick/draw/experiment, необязательные indicator, draw и target. makePracticeQuestion() строит вопрос по реальным значениям видимой свечи; practicePick()/answerPractice()/finishPractice() отвечают за проверку и XP. configurePractice() задаёт воспроизводимое окно; drawScenario()/gradeDraw() отвечают за учебные волны и допуски, practiceState.marks хранит t, стрелки не ставят отметки автоматически, drawMark ставит выбранный экстремум; drawClear очищает обе точки; hypotheticalCandle() и renderExperiment() сравнивают неизменный исходник с моделью при изменении C в пределах ±5%, сохраняя H/L; не допускать оплаты повторных прохождений.
- labTasks — конструктор свечей. cityQuests, dependencies, simulateCity() — условная экономика; коэффициенты не эмпирические. switchMode() сохраняет сессию демо-рынка при переключении.
- save()/profile()/renderSkills() — единая система прогресса. localStorage key trading-x-v1; поля solved (числовые ID), solvedIds (стабильные ID), index, lessonId, reviewPending, courseChapter, courseLevel, netSolved, labSolved, practiceSolved (строковые ID), netIndex. Не менять ключ без миграции. При недоступном localStorage игра должна работать в памяти. XP: 100 урок, 75 лаборатория/практикум, 150 город; без штрафа за ошибки, без наград за сделки.
- games/index.html — каталог. Корневой sw.js обслуживает шахматы, должен исключать trading-x/; не вводить cache-first навигацию. .github/workflows/pages.yml публикует main. Не считать запись в GitHub подтверждением публичного деплоя.

## UX и педагогика
- Trading X размещается последним в games/index.html, в разделе финансового просвещения. Не удалять краткое предупреждение перед входом и расширенную памятку в игре: учебная условность, возможные неточности, риски реальных инвестиций и отсутствие финансовых рекомендаций. Авторская идея — использование свободных средств для развития общества, сбережений и образования вместо вредящих здоровью и импульсивных трат, без принуждения и обещаний дохода.
- Документ прокручивается целиком. Никаких sticky/fixed графиков, locked body, внутренней панели скролла или скрытия вопросов при изменении размера. Canvas touch-action:auto; pointerdown/up с порогом движения и pointercancel. Кнопки стрелок и клавиатура доступны; проверять 320px.
- Вопрос непосредственно связан с показанным примером; вычислять правильный ответ, не подменять историю. Округление ответа должно соответствовать отображению. Если данных недостаточно, объяснять это. Не считать индикатор прогнозом; два закрытия не доказывают тренд.
- Вознаграждение — спокойная анимация и объяснение, возможность закрыть карточку. Не блокировать скролл, не делать навязчивые модалки; учитывать prefers-reduced-motion. Звук только opt-in. Не собирать данные пользователя без явного согласия.
- Детские задания: условные деньги и совместное обсуждение, не призыв к торговле/кредиту/реальному счёту. Общественная польза ≠ гарантированная доходность. Резерв и отказ от вложения полноценны. Первичное и вторичное финансирование различать.
- Не заимствовать дословно материалы учебных платформ. Проверять факты и формулы по первоисточникам; отмечать гипотезы и условные допущения.

## Проверка перед записью
1. Синтаксис всех JS scripts (Node new Function), уникальность DOM ID, ссылки меню, длины Q/lessons и существование стабильных ID.
2. Пройти весь учебный путь, неправильный/правильный/повторный ответ; XP начисляется один раз; закрытие карточек, выбор свечи, индикаторы, сброс и сохранение прогресса. Проверить валидность OHLC и диапазоны индикаторов, недостаток данных.
3. Проверить городской резерв, первичный/вторичный канал, шоки и ограничение индексов; демо-рынок не раскрывает будущие свечи и сохраняет сессию при переключении.
4. Проверить CSS и реальные viewport: 320×568, 390×844, 768×1024, 1440×900; свайп по графику не равен тапу, вертикальный скролл доступен, увеличение не скрывает панель. Проверить iframe отдельно.
5. При наличии Node выполнить node trading-x/tests/smoke.cjs (тестовый файл уже существует); реальные Chromium/WebKit и HTTP smoke проверять отдельно. Не выдавать DOM-заглушку за браузерный E2E. Записать команду, число проверок, ограничения.
6. После записи повторно fetch изменённые файлы, проверить SHA и изменения. Обновить ROADMAP.md только по реально выполненным пунктам. В итоговом отчёте дать TX-ID, версию, commit/URL, результаты тестов, блокеры и следующий шаг.
