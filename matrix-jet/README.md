# MATRIX JET — Telegram Mini App во вселенной «Сюжета Икс»

**Автор вселенной:** Югатн. **Платформа:** браузер HTML5 Canvas / Telegram WebApp, вертикальный экран. **Версия MVP:** 1.0. **Дата разработки:** 18.11.2026.

**Адрес игры после публикации через GitHub Pages:** https://yugatn.github.io/YUGATNEO_GAME/matrix-jet/

## Концепция

Реакционная аркада, в которой стилизованный истребитель автоматически летит **вверх по экрану (вид строго сверху)**. Пространство прокручивается вниз с возрастающей скоростью. Пилот уклоняется от **турбулентных облаков** и **стай птиц**, выбирая горизонтальную траекторию и эшелон полёта. Игрок получает очки за преодолённую дистанцию, избегание столкновений и удачные манёвры.

На определённых участках появляется световой портал. При его захвате мир темнеет, наполняется зелёными символами матричного кода, и самолёт получает **энергетическую фазовую способность**: на ограниченное время проходить сквозь облака и стаи, не получая урона. Повторные порталы дают новые заряды. Это условный фантастический эффект, не настоящая способность самолёта.

## Основные механики

| Система | Правило |
|---|---|
| Скорость | Автоматический полёт с ускорением от 0,67 до 1,36 условных высот экрана в секунду |
| Горизонтальное движение | Перетаскивание самолёта по сенсорному экрану, касание желаемой позиции или кнопки влево/вправо |
| Высота | Три эшелона: низкий, средний, высокий |
| Переключение высоты | Кнопки ↑ и ↓, вертикальные свайпы по полю или клавиши W/S |
| Читаемость изменения высоты | Низко: масштаб 1,22; средне: 1,00; высоко: 0,78. Масштаб меняется плавно |
| Препятствия | Турбулентные облака и птичьи стаи, у каждого собственный эшелон (H1, H2, H3) |
| Обход | Можно сменить горизонтальную позицию или уйти на другой эшелон |
| Столкновения | Три жизни, краткая неуязвимость после попадания |
| Порталы | Первый примерно через 8,5 секунд; затем примерно раз в 15 секунд |
| После портала | Зелёный матричный код до окончания попытки, два заряда фазового прохода |
| Суперспособность | Кнопка «✦ ПРОХОД СКВОЗЬ» / клавиши F или пробел; неуязвимость 3,25 секунды |
| Очки | Расстояние + бонусы за обойдённые препятствия, узкие пролёты, порталы и фазовые манёвры |
| Завершение | После потери трёх жизней показываются результаты и кнопка повторной попытки |
| Рекорд | Сохраняется в локальном `localStorage` конкретного браузера |
| Пауза | Кнопка II, P/Escape, автоматически при скрытии страницы или переходе в другое приложение |

При подъёме самолёт уменьшается, при снижении становится больше: это художественная визуальная условность для вида сверху, а не симуляция реальных высот и аэродинамики. Коллизии учитывают соотношение сторон телефона, чтобы на высоком экране невидимая область столкновения не была шире видимого препятствия.

### Управление на телефоне

- **Горизонтальный свайп:** двигать самолёт пальцем.
- **Вертикальный свайп вверх/вниз:** перейти на один эшелон выше/ниже.
- **Кнопки слева и справа:** точные небольшие манёвры.
- **Кнопки ↑ и ↓:** изменение эшелона с небольшой задержкой, предотвращающей случайное двойное переключение.
- **Способность:** появляется отдельной кнопкой только после активации портала.
- **Пауза:** не влияет на счёт и не штрафует за отдых.

На компьютере: A/← и D/→ — горизонталь, W/↑ и S/↓ — высота, F/пробел — фазовый проход.

### Матричный визуальный стиль

Чёрный фон, тонкая зелёная координатная сетка, неоновый контур самолёта, бегущие линии скорости, читаемые силуэты облаков и птиц. После портала появляются падающие символы цифрового кода и более яркое зелёное свечение. Истребитель и все объекты нарисованы оригинальными векторными линиями Canvas и SVG, кадры и изображения известных фильмов не используются.

### Очки и честность

- Пройденная дистанция: примерно 0,48 очка на условный метр
- Обход препятствий: 25 очков + небольшой бонус за серию
- Близкий пролёт: 45 очков
- Портал: 240 очков
- Активация способности: 55 очков
- Прохождение опасности сквозь неё в фазовом режиме: дополнительные бонусы
- Незащищённое столкновение снижает накопленный бонус, но не делает счёт отрицательным

Результаты — **игровые показатели**, не диагностический тест скорости реакции или доказательство улучшения когнитивных функций. Фантастические полёты в игре не являются руководством по авиации.

## Структура

```text
matrix-jet/
  index.html               стартовая заставка, мобильный интерфейс
  engine.js                чистая логика полёта, высоты, столкновений и очков
  game.js                  Canvas-анимация, ввод, Telegram SDK, рекорды
  icon.svg                 оригинальная иконка
  manifest.webmanifest     PWA-манифест
  sw.js                    отдельный кэш файлов для повторного офлайн-запуска
  README.md                описание, инструкции, ограничения
tests/
  matrix-jet.test.cjs       игровые сценарии
  matrix-jet-ui.test.cjs    моделирование мобильных касаний/паузы/интерфейса
.github/workflows/
  matrix-jet-ci.yml        CI-проверки
```

### Локальный запуск

```bash
python3 -m http.server 8000
# затем http://localhost:8000/matrix-jet/
```

Простое статическое приложение не требует NPM для игры. Для запусков автоматических UI-тестов:

```bash
npm install --no-save jsdom@26.1.0
node --check matrix-jet/engine.js
node --check matrix-jet/game.js
node --test tests/matrix-jet.test.cjs tests/matrix-jet-ui.test.cjs
```

## Подключение Telegram Mini App

1. После объединения изменений с `main` убедиться, что GitHub Pages действительно отдаёт игру по HTTPS.
2. В [@BotFather](https://t.me/BotFather) выбрать собственного бота или создать его.
3. Выполнить `/newapp` для Mini App или `/setmenubutton` для меню бота, указать адрес: `https://yugatn.github.io/YUGATNEO_GAME/matrix-jet/`.
4. Проверить в Telegram на iPhone и Android: старт, вертикальный режим, свайпы, эшелоны, матричные порталы, способность, видимость кнопок, запись рекорда.

Официальная справка: https://core.telegram.org/bots/webapps

**Не требуется** передавать токен бота или данные аккаунта. Telegram WebApp SDK используется для готовности интерфейса, развёртывания окна и тактильного отклика при наличии поддержки. Игра работает и в обычном браузере. Онлайн-таблица рекордов между устройствами не реализована, поскольку GitHub Pages не имеет авторитетного игрового сервера.

## Протокол тестирования на телефонах

1. В вертикальном режиме убедиться, что все четыре кнопки маневрирования видны и не перекрыты системной панелью Telegram.
2. Проверить, что движение и выбор высоты возможны одновременно; быстро сменить эшелон и увидеть изменение размера самолёта.
3. Убедиться, что несоответствующие эшелону препятствия проходят без столкновения.
4. Найти портал, войти в него и активировать фазовую способность; убедиться в расходе зарядов и завершении её действия.
5. Получить три столкновения, увидеть финальный экран и начать новую игру.
6. Проверить отсутствие непредсказуемых фризов при длительном полёте, особенно на старых iPhone.
7. Закрыть и повторно открыть Mini App — личный рекорд сохраняется в том же браузере.
8. Проверить в Safari и Telegram WebView отдельно; автоматические Node.js-тесты не заменяют проверку реального мобильного устройства.

## Следующее расширение

Возможны уровни сложностей, новые погодные условия, развивающие упражнения на переключение внимания, достижения, дополнительные размеры крыльев/истребителей, облачный рейтинг при наличии защищённой серверной части. Изменение авторского канона «Сюжета Икс» не требуется: это отдельный игровой модуль.
