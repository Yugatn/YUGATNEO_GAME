# YUGATNEO · SPIRAL RUN — Telegram Mini App

**Авторская игровая вселенная:** Югатн / «Сюжет Икс». **Версия:** MVP 0.2, 18 ноября 2026.
**Статус:** исходники готовы для браузера; реальный запуск через Telegram BotFather возможен только после настройки бота владельцем. Тесты GitHub Actions подтверждают логику и синтаксис, не гарантируют одинаковый FPS в мобильном Telegram WebView.

## Демо и архитектура

Публичный HTTPS-адрес после публикации ветки в `main` и успешного GitHub Pages:
https://yugatn.github.io/YUGATNEO_GAME/matrix-sprint/

Сохранён прежний режим `/runner/` в репозитории — никаких его файлов мы не переписывали. Новая версия — самостоятельная мини-игра, использующая Canvas 2D с перспективной проекцией игрового маршрута. Это **2.5D-визуализация 3D-поворотов**, не Three.js/WebGL и не свободный мир 3D. Такой подход снижает нагрузку на телефон и работает без библиотек.

- `index.html`: полноэкранный интерфейс, авторская заставка с бегуном в круглых очках, понятные сенсорные зоны и клавиши, встроенный официальный Telegram SDK.
- `engine.js`: чистое игровое ядро: процедурные сегменты спирали, разметка полос, физика прыжка, опасности, обязательный поворот на перекрёстке, подъём на платформу, активация портала, агенты, суперимпульс и формула очков.
- `game.js`: Canvas 2D-рендер трассы сверху и сзади, плавный разворот камеры, матричный дождь символов, бегун с очками, агенты, UI, сенсорное управление и Telegram HapticFeedback.
- `icon.svg`: оригинальная графическая иконка.
- `manifest.webmanifest`: PWA-манифест.
- `sw.js`: офлайн-кэш только публичных файлов приложения, не пользовательских персональных данных.
- `../tests/matrix-sprint.test.cjs`: автоматизированные проверки правил игры, клавиш/ID и состава файлов.
- `../.github/workflows/matrix-sprint-ci.yml`: `node --check` и `node --test`.

## Игровой процесс

### До портала

Бегущий персонаж в круглых тёмных очках автоматически движется вперёд по трёхполосной спиральной трассе. **Вид по умолчанию сверху.** Игрок меняет полосу коротким касанием левого или правого края экрана, а по центру прыгает. Под ногами — последовательность участков, часть из которых поворачивает влево или вправо на 90 градусов. Перед поворотом появляется стрелка. Игрок обязан **заранее нажать нужную сторону** в пределах последних 20 условных метров участка, иначе произойдёт выбывание.

Есть препятствия-блоки, перекладины и выступающие ступени. Большинство объектов можно либо обойти по соседней полосе, либо перепрыгнуть; на каждых нескольких участках встречается порог с обязательным прыжком, после которого дорога оказывается на новом уровне высоты. Уровень визуально отражается изменением высоты платформ.

Через некоторое время над одной из полос появляется световой портал. Для активации нужно оказаться на нужной полосе и **впрыгнуть в него**. Пропущенный портал не завершает игру: последующие будут появляться снова.

### После портала

Вся игра переключается в неоново-зелёную палитру с бегущими символами матричного кода. Состояние остаётся до конца попытки. Теперь бегуну доступны три заряда энергетического импульса, которые постепенно восстанавливаются. Абстрактные агенты-роботы появляются впереди и движутся навстречу. Их можно обойти или перепрыгнуть, а если они находятся в той же полосе в зоне поражения — нейтрализовать импульсом. Нет крови, насилия над реальными людьми или кооперативной агрессии. Игра не копирует персонажей, логотипы и кадры защищённых фильмов.

### Две камеры

- **TOP:** вид сверху, наиболее удобный для планирования пути и переключения полос.
- **REAR:** позади персонажа, с перспективным сужением дороги, приближающимися препятствиями и поворотом изображения вместе с трассой.

Переключение в любой момент — кнопка `ВИД` или клавиша `V`. Физика, дистанция и счёт при этом не меняются.

### Управление

| Действие | Экран телефона | Компьютер |
|---|---|---|
| Прыгнуть | центр поля / большая кнопка «Прыжок» | Пробел, ↑, W |
| Влево | левый край / «Налево» | A, ← |
| Вправо | правый край / «Направо» | D, → |
| Поворот на перекрёстке | нажать указанную сторону у конца трассы | соответствующая стрелка |
| Импульс в Матрице | «✦ Импульс» (только после портала) | F |
| Камера | «ВИД» | V |
| Пауза | «Ⅱ» | P / Escape |

Пауза автоматически включается при уходе Telegram на фон, скрытии страницы и переключении приложения. Таймер матча не продолжается в фоне, **штрафа за перерыв нет**.

### Счёт и результат

Очки начисляются за пройденный путь, преодолённые препятствия, удачные уклонения, нейтрализацию агента, портал и подъём на новый уровень. Формула локальная и воспроизводимая; это не официальный тест скорости реакции и не доказательство роста интеллекта.

При столкновении выводится причина, итоговый счёт, дистанция, количество преодолённых препятствий и агентов. `localStorage` хранит только **личный числовой рекорд**. Таблица лидеров Telegram, регистрация пользователей, облачное сохранение и мультиплеер **не реализованы**. Приложение не читает `initDataUnsafe` и не отправляет персональные данные пользователя на сервер.

## Как запустить в Telegram

### Шаг 1. Разместить веб-файлы

Этот проект опубликован через GitHub Pages после объединения изменений в `main`. Проверить, что открывается URL:
`https://yugatn.github.io/YUGATNEO_GAME/matrix-sprint/`.

Если по ссылке открывается 404, сначала проверить `Settings → Pages` и успешную публикацию GitHub Actions: **не объявлять Telegram Mini App рабочим, пока адрес не доступен по HTTPS**.

### Шаг 2. Подключить своего Telegram-бота

Открыть официальный [@BotFather](https://t.me/BotFather), выбрать своего бота (или создать его через `/newbot`), затем:

- Для **Main Mini App**: `/newapp`, выбрать бот, задать название, уникальный `short_name`, описание и ссылку на опубликованную страницу.
- Для запуска **из меню бота**: `/setmenubutton`, выбрать бота, указать название вроде «SPIRAL RUN» и тот же HTTPS URL.
- После сохранения открыть бота в Telegram и проверить запуск через кнопку. BotFather управляет этой настройкой, GitHub не может выполнить её вместо владельца.

По зарегистрированному `short_name` Telegram может создавать ссылку вида `https://t.me/<bot_username>/<short_name>`; **не подставлять выдуманное имя бота**.

**Не присылать токен бота в чат и не размещать его в GitHub.** Данная игра является статической и не нуждается в Bot API токене. Если позднее потребуется облачный рейтинг, понадобится отдельный сервер, который валидирует `Telegram.WebApp.initData` по документированному алгоритму подписи.

Источник: https://core.telegram.org/bots/webapps

### Шаг 3. Проверить мобильный WebView

В Telegram на iPhone и Android проверить:
- стартовую заставку, полноэкранное поле, отсутствие перекрытия кнопок системными областями;
- горизонтальные и вертикальные ориентации, CSS `100dvh`, safe-area;
- касания левее 30%, правее 70% и по центру;
- поворот на пересечении участков, возвышение, портал и стрельбу;
- режим задней камеры, анимацию смены направления, частоту кадров;
- сворачивание/восстановление Telegram и сохранение личного рекорда после перезапуска.

Гироскоп, свободное вращение камеры, настоящая 3D-физика, сетевой рейтинг и внутриигровые покупки **не входят в MVP**.

## Разработка и проверки

Локально из корня репозитория:

```bash
python3 -m http.server 8000
```

Играть: `http://localhost:8000/matrix-sprint/`.

Тесты:

```bash
node --check matrix-sprint/engine.js
node --check matrix-sprint/game.js
node --test tests/matrix-sprint.test.cjs
```

Для публикации как Telegram Mini App нужен публичный HTTPS; `localhost` годится только для разработки.
