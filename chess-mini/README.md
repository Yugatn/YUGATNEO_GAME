## Функции

### 1. Партия вдвоём на одном устройстве

Два человека выбирают белые и чёрные, передают друг другу один телефон или планшет. Полный шахматный движок `chess.js@0.10.3` проверяет все правила: шах, мат, пат, рокировку, взятие на проходе, превращение пешек, повторение позиции и завершения партии. Есть список ходов, шахматные часы (3, 5, 10, 15 минут или без часов), переворот доски, отмена и экспорт PGN.

### 2. Против компьютерного соперника

Три ступени сложности: начинающий, любитель, сложнее. Упрощённый локальный поисковый алгоритм `minimax` с альфа-бета-отсечением на глубину примерно 1/2/3 полухода и эвристикой материального баланса. Он не заменяет Stockfish и не соответствует спортивной Elo-калибровке.

Компьютер играет чёрными. Игра полностью на устройстве, без запросов на сервер для выбора хода.

### 3. Включаемые подсказки

`Показывать легальные ходы` — выделение возможных пунктов назначения для выбранной фигуры. `Без подсказок` — никаких маркеров легальных ходов. Отдельная кнопка `✦ Подсказать ход` показывает откуда и куда ходить (для обычных партий это всего лишь **эвристический вариант** локального алгоритма, не гарантированно сильнейший ход; в головоломке показывает искомое решение).

При решении задачи включение подсказки уменьшает бонус наполовину. Неверные попытки снижают награду дополнительно. Нет санкций за отключение подсказок, игра остаётся доступна.

### 4. Шахматные головоломки и бонусы

Первый набор — **12 коротких офлайн-задач**, созданных для этого приложения по классическим темам:

- Мат в один: последняя горизонталь, ранний ферзевый мат.
- Вилка: конь одновременно атакует короля и ферзя.
- Выигрыш материала: ладья или слон берёт ферзя.
- Превращение пешки: выбор правильной фигуры для последней горизонтали.

Каждая задача имеет собственный ID, FEN (или начальную последовательность), ход-ответ в координатах UCI, описание, тему и награду. `puzzles.js` проверяет корректность ответа через chess.js, а тестовый CI подтверждает легальность заданных ходов, FEN и заявленных матов.

Награда выдаётся **только за первое решение** идентификатора; повторные решения доступны для тренировки, но не увеличивают бонус. Пользователь может менять категорию и переходить к следующей задаче, не решая предыдущую.

При создании заданий изучались общие тематические категории шахматной тактики и принципы открытого набора [Lichess Puzzle Database](https://database.lichess.org/#puzzles). **Задачи не импортированы из базы Lichess**: они скомпонованы вручную и валидируются игровым движком. Lichess предоставляет оригинальные данные задач под CC0, что позволит безопасно импортировать дополнительные подготовленные наборы с указанием источника.

### 5. Матричная стилистика

- По умолчанию матричная изумрудная шахматная доска и зелёные подсветки.
- Четыре оформления доски: Матрица, киберсиний, фиолетовый, классический.
- Три оформления фигур: классические Unicode, контурные (общие чёрные силуэты с разным цветом для сторон), буквенные.
- Четыре палитры фигур: мята, золото, ледяной синий, розово-фиолетовый.
- Цвет и фигуры можно выбрать до первого хода или изменить без разрушения партии; параметры сохраняются локально.

### 6. Локальный рейтинг

Данные сохраняются в `localStorage` на **конкретном устройстве и в конкретном браузере Telegram**:
- результаты завершённых партий по указанным именам;
- условные игровые рейтинговые очки, пересчитываемые приближённой формулой Elo с K=24;
- победы, ничьи, поражения;
- совокупные баллы задач и ID впервые решённых задач;
- оформление и включение подсказок;
- текущая обычная партия (PGN).

**Это не проверенный спортивный Elo, не официальный рейтинг ФИДЕ и не глобальная таблица Telegram.** Имена в локальной игре не являются подтверждёнными аккаунтами, результаты не защищены от правки localStorage. Очки изолированы от Roblox и не имеют денежной стоимости.

## Почему пока без онлайн-игры

GitHub Pages — статический HTTPS-хостинг без постоянного процесса, базы матчей, блокировок ходов, серверной авторизации или WebSocket-матчмейкинга. Хранить общий рейтинг и принимать легальные сетевые ходы через один GitHub Pages корректно **нельзя**.

Для настоящего онлайн-режима потребуется отдельная серверная часть (например Cloudflare Durable Objects / Workers, Supabase Realtime с правилами доступа и серверными транзакциями). Сервер будет проверять Telegram `initData` по HMAC, сроки данных, очередь, очередность ходов, шахматные правила, результаты и отмену транзакций. **Нельзя доверять `initDataUnsafe`, localStorage или присланному с клиента рейтингу как достоверным данным**. Ни одного токена бота в публичных исходниках не хранить. Этот этап отложен, поскольку пользователь разрешил полноценную офлайн-версию.

## Подключение к Telegram

Страница Mini App — статический HTML5 на GitHub Pages. Для связи с ботом владельцу нужно открыть [@BotFather](https://t.me/BotFather), выбрать бота, выполнить `/newapp` или `/setmenubutton` и указать публичный HTTPS-адрес:

`https://yugatn.github.io/YUGATNEO_GAME/chess-mini/`

Telegram WebApp SDK подключён в `<head>`; страница открывается и в обычном браузере без Telegram. Приложение не запрашивает персональные данные Telegram и не использует Bot API токен.

Официальная документация: https://core.telegram.org/bots/webapps

## Локальная разработка и тестирование

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/chess-mini/
```

В CI тестовый движок устанавливается отдельно:

```bash
npm install --no-save chess.js@0.10.3
node --test tests/chess-mini.test.cjs
```

Проверки охватывают 12 корректных головоломок и реальные маты, интерфейс, относительные ссылки, сохранение рейтинга, сохранение игровой математики, уникальные DOM ID и структуру кэша.

**Перед объявлением релиза:** открыть в Telegram на iOS/Android; проверить диалог превращения пешки, мат и пат, все задачи, часы, длительный 3-й уровень бота, переключение темы и фигур, локальное сохранение, перезагрузку WebView, работу без сети после первого успешного открытия, условия доступа к шахматному CDN.
