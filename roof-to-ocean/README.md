# Крыши → Океан

Самодостаточный прототип браузерной 2D-игры без библиотек, сборки, серверов и внешних ассетов.

## Запуск

Откройте `index.html` в браузере или разместите файл на GitHub Pages.

### Сцены

1. Подбежать к девятиэтажке и подняться по лестнице до 9-го этажа.
2. Забег по крышам с прыжками через пропасти.
3. Бег по улице с обходом автомобилей, людей и животных.
4. Полёт на самолёте с набором/снижением высоты и уклонением от опасностей.
5. Мотоциклетная аркада со сменой полос.
6. Сёрфинг с уклонением от акул и медуз.
7. Финал — отдых героя на шезлонге у моря.

Порталы включают матричную визуализацию, ускорение ×1.35 и двойной прыжок на этапах бега. Есть очки, здоровье, контрольные точки, рестарт текущего этапа, пауза, звук, полноэкранный режим и сенсорное управление.

### Управление

- `Пробел` или `↑` — прыжок на крышах и улице; два нажатия в режиме Матрицы дают двойной прыжок.
- `↑`/`↓` — высота полёта.
- `←`/`→` — менять полосу на байке и во время сёрфинга.
- `P` — пауза, `R` — начать заново.
- На мобильных устройствах — экранные кнопки и касания самого игрового поля.

## Развёртывание на GitHub Pages

Загрузите `index.html` в отдельную папку или в корень репозитория GitHub Pages. Если файл расположен в папке `roof-to-ocean/`, адрес будет вида `https://<username>.github.io/<repository>/roof-to-ocean/`.

## Особенности

- Все персонажи и объекты рисуются на Canvas 2D; не требуется скачивать картинки.
- Поведение сцены и состояние игры разделены, каждая стадия имеет свою механику.
- Столкновения без насилия над персонажами, животными или прохожими.
- В `window.ROOF_TO_OCEAN` есть команды для ручного тестирования переходов между сценами.
