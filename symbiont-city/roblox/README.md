# «СИМБИОНТ: Развивающий мир» — перенос механик в Roblox

**Статус:** рабочий портируемый игровой модуль и архитектурный план. **Опубликованной Roblox-игры или связанного place-файла пока нет.** Этот каталог не содержит API-токенов, персональных данных или родительских профилей.

## Что уже доступно

`SharedCityModel.module.luau` — самостоятельный Roblox Luau ModuleScript, повторяющий игровые показатели и три аварийные ситуации из статической Telegram Mini App «Город решений». Реализованы:

- семь взаимосвязанных социальных инфраструктур: вода, медицина, обучение, транспорт, питание, жильё и связь;
- три сценария с ограниченным количеством ресурсных действий;
- интерактивная механика поддержки одной службы, отражающаяся на других;
- расчёт средней доступности и положения наиболее уязвимого района;
- ограничение повторных действий и безопасное завершение раунда.

Это **игровая модель взаимосвязи**, а не научная теория об обществе как буквальном организме. Образ центральной нервной системы — авторская метафора «Амбивалентного Солипсизма», допускающая критическое рассмотрение. В детской версии не требуется соглашаться с политическими или метафизическими тезисами.

## Пример подключения в Roblox Studio

1. Создать новую Roblox Studio Experience в собственном аккаунте.
2. В `ReplicatedStorage` добавить ModuleScript с именем `SharedCityModel` и вставить содержимое этого файла.
3. Для локального прототипа вызвать из LocalScript:

```lua
local Model = require(game.ReplicatedStorage.SharedCityModel)
local round = Model.new("water", 3)
print(Model.metrics(round))
Model.repair(round, "water")
print(Model.metrics(round))
Model.finish(round)
```

4. Связать с SurfaceGui/ScreenGui или 3D-объектами города: нажатие на больницу/воду/транспорт вызывает `Model.repair` и перерисовывает статусы.
5. Для общего мультиплеерного мира перенести **доверенную серверную** логику на сервер, проверять RemoteEvent-запросы, ограничения действий и частоту запросов. Клиентские показатели нельзя считать достоверными.
6. Сохранение в DataStore и взаимодействия игроков подключать только после тестов конфиденциальности, согласия родителей при необходимости, возрастных ограничений Roblox и правил модерации.

## Следующие зоны развивающего мира

- **Школа вопросов:** совместные задания по эмпатии, слушанию и коучинговым вопросам без псевдопсихотерапии.
- **Лабиринт восприятия:** возрастные уровни и бегущий человечек, цифровые порталы, логические задания, память маршрутов.
- **Инфраструктурная долина:** осязаемые водопровод, клиника, транспорт, сад и сигнал; последствия аварии распространяются по району.
- **Площадь диалога:** безопасное обсуждение различных потребностей и мирных способов исправления проблем; без пропаганды политической позиции.
- **Мастерская решений:** проверка информации, защита приватности, групповые строительные задачи.

**Медицинские взрослые сценарии 18+ не следует переносить в общедоступные детские Roblox-зоны.** Для их внедрения потребуется отдельный защищённый режим с соответствующим возрастным контролем и педагогической проверкой; простая установка возраста пользователем не является подтверждением совершеннолетия.
