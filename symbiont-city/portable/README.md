# Переносимые уровни СИМБИОНТ (прототип данных)

`levels.v1.json` — три новых **проектных** эпизода для общего движка веб-игры и Roblox, без изменения действующего интерфейса и без притворной публикации Roblox Experience.

## Сценарии
1. **Вода для каждого**: устранение взаимозависимых инфраструктурных проблем (6+).
2. **Мост сотрудничества**: распределение ролей, безопасное строительство и взаимопомощь (6+).
3. **Совет города**: сравнение свидетельств и проверяемые мирные формы гражданского участия (10+).

## Перенос
- Веб: загрузить JSON, валидировать `version`, `id`, допустимый возраст и действия, затем передать в существующую игровую UI-модель. **Загрузка в веб-игре пока не реализована.**
- Roblox: перевести JSON в Lua-таблицы через `HttpService:JSONDecode` либо встроить локальную строку; весь переход состояния и проверку ресурсов выполнять **на сервере**. Внешний HTTP и загрузка кода из интернета не нужны.
- Проверки: уникальность идентификаторов, невозможность отрицательных запасов, однократная награда, непрерывность маршрута, несколько игроков, мобильное управление, доступность.
- Для одиночного режима игрок по очереди исполняет все роли; игровой прогресс не равен диагнозу или оценке личности.

## Педагогические границы
Модель «общество как организм с центральной нервной системой» — **авторская метафора**, не эмпирический закон. Изучать можно взаимозависимость людей, общественные институты, историю общественных преобразований и разные подходы к проблемам. Никакая политическая идентичность не должна быть условием победы, а ребёнка нельзя направлять к реальной политической агитации.

## Взрослый модуль отдельно
Существующая «Осознанное родительство» сохраняется в 18+ веб-разделе. Доказательно корректные формулировки: отсутствие известной безопасной дозы алкоголя при беременности; вред курения и пассивного дыма; частые отвлечения родителей на телефон **могут** нарушать взаимодействие и ассоциированы с рядом детских исходов, но само использование телефона при ребёнке **не доказывает** формирование зависимости. См. [CDC](https://www.cdc.gov/alcohol-pregnancy/about/index.html), [NICHD](https://www.nichd.nih.gov/health/topics/preconceptioncare/conditioninfo/healthy-pregnancy), [JAMA Pediatrics](https://jamanetwork.com/journals/jamapediatrics/fullarticle/2833506).
