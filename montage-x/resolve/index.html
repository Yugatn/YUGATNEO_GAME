Шесть учебных заказов: сначала определите задачу фильма, затем настройки проекта и монтажное решение. Ни один формат или приём не подходит для всех случаев.

Настройки выбранного проекта

Порядок настройки нового проекта

Project Manager → New Project. Откройте Project Settings (значок шестерёнки). Master Settings → Timeline Resolution / Timeline Frame Rate / Playback Frame Rate. Настройте формат до импорта и создания таймлайна; Resolve может ограничить изменение FPS после начала проекта. Для другого FPS создайте отдельный таймлайн или проект и проверьте соответствие.

При предложении изменить FPS после импорта руководствуйтесь целевым форматом, а не первым случайным клипом. Проверьте Image Scaling, обрезку кадра и соотношение сторон.

Цвет: Rec.709, Log и RAW

Для SDR — выбранный рабочий процесс Rec.709, типичный контрольный выход Rec.709 Gamma 2.4. Для смешанного Log удобно использовать DaVinci YRGB Color Managed с правильно определённым Input Color Space каждого источника и SDR-выходом; для ручного CST не дублируйте преобразования RCM/LUT. RAW декодируется по настройкам Camera RAW и профилю камеры; HDR требует отдельной спецификации и подходящего мониторинга.

Оцените тестовый экспорт в целевом проигрывателе; особенности цветоуправления macOS не являются причиной менять стандарт выдачи вслепую.

Производительность и сохранность

Playback → Timeline Proxy Resolution → Half/Quarter (если необходимо); Proxy Handling → Prefer Proxies, если созданы прокси. В Project Settings → Master Settings → Optimized Media and Render Cache, Working Folders — проверьте формат и папки. Preferences → User → Project Save and Load — Live Save и Project Backups. Отдельно копируйте исходники и проект .drp; .drp не включает медиа.

macOS: нативная сборка, совместимость плагинов и давление памяти; Windows: поддерживаемые GPU и драйверы; Linux: сверяйте дистрибутив, драйверы, Free/Studio и таблицу кодеков. Debian не автоматически поддерживается. Не отключайте защиту ОС.

Настройте проект по брифу

Выберите параметры целевой выдачи и цветовой процесс. Подсказки доступны в справочнике. В брифах используется стандартный видеопроизводственный звук 48 кГц; для Log здесь выбран именно управляемый цветовой процесс RCM. Другие корректные рабочие процессы возможны.

Критерии относятся к заданному брифу, а не ко всем проектам. Настройки Resolve автоматически не меняются.
