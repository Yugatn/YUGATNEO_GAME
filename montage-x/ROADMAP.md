# Монтаж X — дорожная карта

## v1.2
- Раздел «Горячие клавиши» внутри Монтаж X: отдельная страница shortcuts/ с возвратом в основной тренажёр. 80 команд (Resolve 20, Premiere 30, Final Cut 30), 130 назначений по пяти профилям: Resolve/Premiere Windows и macOS, Final Cut macOS.
- Поиск по названию и клавишам, пять категорий, три режима: выбор комбинации, воспроизведение экранными клавишами или физической клавиатурой, повторение ошибок. Два верных ответа подряд — критерий закрепления, история разделена по программе и ОС.
- Источники: Adobe https://helpx.adobe.com/premiere/desktop/get-started/keyboard-shortcuts/default-keyboard-shortcuts.html и https://helpx.adobe.com/premiere/desktop/edit-projects/intro-to-editing/edit-video-in-premiere.html ; Apple https://support.apple.com/guide/final-cut-pro/keyboard-shortcuts-ver90ba5929/mac ; Blackmagic Design https://www.blackmagicdesign.com/products/davinciresolve/edit/ и дополнительная таблица https://davinciresolve21.com/blog/shortcuts . Resolve — первоначальная выборка стандартных назначений Edit, не сплошной аудит официального руководства.
- 23 проверки в симулированном DOM пройдены; синтаксис обеих страниц проверен. Физическая клавиатура, реальные браузеры и редакторы не тестировались. Перехватываемые ОС/браузером сочетания можно вводить экранно. Используется физическая US QWERTY-позиция; Fn не измеряется отдельно. Список не исчерпывающий.
- Далее: расширить Resolve (Cut, Color, Fairlight, Fusion, Deliver), затем Premiere и Final Cut; добавить сравнительный режим, сценарии реального монтажа по клавишам, звуковой предпросмотр, браузерную регрессию.

## Далее
1. Расширить визуальный материал: анимация движения, траектории камеры, крупность и смена ракурса с непрерывной фазой.
2. Практикум на монтажной шкале: обрезка клипов, перестановка, J/L, перебивки, регулирование ритма, сравнение вариантов.
3. Добавить оригинальные короткие учебные видеосцены и звуковые примеры, не использовать чужие фильмы без прав.
4. Сюжетная кампания: ассистент монтажа → монтажёр → режиссёр монтажа; задачи с различными целями и объяснениями.
5. Банк продвинутых задач: монтаж по свету, цвету, композиции, фазе движения, скорости, экранному направлению, драматургии и смыслу. Не путать частные педагогические классификации с общепринятыми правилами.
6. Экспорт прогресса, доступность клавиатуры, тесты Safari/Chrome на телефонах, адаптация к DaVinci Resolve через учебные сценарии.
