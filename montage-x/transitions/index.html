Атлас монтажных приёмов

Выбирайте склейку и звук под смысл сцены. Переход не обязан сопровождаться SFX; впечатление зависит от контекста.

Библиотека SFX

Учебный синтез, не профессиональные записи Foley. Проверяйте лицензии при подборе реальных эффектов.

Монтажная схема

Условные графические схемы, не реальные съёмки. Для J/L показана схема дорожек, выбранный звук — иллюстрация, не монтаж настоящих реплик. Для сложных приёмов — схематическое обозначение.
