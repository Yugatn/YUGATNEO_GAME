Монтаж по музыкальным фразам

Размечайте доли, такты и фразы. Выбирайте момент склейки по смыслу: не каждый удар требует смены изображения. Учебная сцена из четырёх планов, оригинальный синтезированный ритм; не импорт реальной музыки.

Фиолетовые — начало четырёхтактовой фразы; золотые — начало такта; серые — доли. Снизу условная разметка акцентов.

Монтажные точки

Сетка строится от абсолютного времени музыкального события. При дробном числе кадров на долю округляется каждая позиция отдельно, без накопления ошибки.

Применение в Resolve

Определите реальную музыкальную структуру на слух и по форме волны. Используйте M для маркеров в нужном контексте, Shift+↑/↓ для перехода по маркерам и ←/→ для покадрового уточнения. Уточните точный момент атаки, а не только BPM. Проверьте в Keyboard Customization свою раскладку.

Сильная доля подходит для раскрытия, слабая — для продолжения движения; синкопа может нарушить ожидаемый рисунок. Иногда удержание плана через несколько ударов лучше частых склеек. Эти эффекты контекстны.
