# Симбионт — браузерный мини-тамагочи

## Возможности
- Пять оригинальных существ: Симбионт, Звёздный кот, Лисёнок, Дракончик и Робо-друг. Выбор при первом запуске и в меню «Выбрать питомца».
- Изменение имени, цвета и вида питомца **без удаления накопленного опыта**.
- Движение питомца по сцене: автоматически выбирает точки назначения и плавно перемещается. Клик или касание мира задают новое место прогулки.
- Режим прогулки / остановки.
- Автоматические сутки по местному времени устройства: день 07:00–18:59, ночь 19:00–06:59. Ручной цикл: авто → ночь → день → авто.
- Ночью (22:00–06:59) питомец обычно спит; игровое взаимодействие может его разбудить.
- Исходные показатели ухода, развитие и упражнения на эмпатию сохранены.
- Сохранение в `localStorage`, отдельный Service Worker для офлайн-доступа после установки.

## Файлы
- `index.html` — интерфейс и модель ухода/сохранений;
- `world.js` — самостоятельные SVG-персонажи и перемещение в мире;
- `world.css` — сцена, эффекты и адаптивная панель выбора;
- `sw.js` — локальный офлайн-кэш;
- `manifest.json`, `icon.svg` — PWA.

## Совместимость сохранений
Используется существующий ключ `yugatneo-symbiont-tamagotchi-v1`. Старые данные загружаются без сброса опыта, счётчика добрых действий и состояния. Новые поля `species`, `timeMode`, `walking` получают значения по умолчанию. Сохранённое ранее `night: true` преобразуется в ручную ночь.

## Контрольные проверки
1. Впервые открыть игру, выбрать каждого из пяти питомцев и убедиться, что силуэты различаются.
2. Нажать «Свободная прогулка», дождаться самостоятельного движения и нажать на новое место в сцене.
3. Проверить три режима времени и автоматический переход дня в ночь по локальным часам.
4. Внести прогресс уходом, затем сменить питомца: опыт и показатели должны сохраниться.
5. Перезагрузить страницу: имя, облик, опыт, режим времени и режим прогулки сохраняются.
6. Проверить на узком экране смартфона (320–390 px), в том числе прокрутку окна выбора.
7. Проверить кэширование после первого запуска онлайн: открыть повторно офлайн.

### Ограничения
Данные остаются на устройстве и не синхронизируются между браузерами. Это одна активная сущность со сменяемым видом, а не отдельные независимые профили нескольких питомцев.
