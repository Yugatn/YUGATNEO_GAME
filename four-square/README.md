# КВАДРАТ — Telegram Mini App

**Автор правил:** Югатн. Мини-игра для проекта YUGATNEO_GAME. Исходники: HTML/CSS/JavaScript без внешнего игрового движка; работает в браузере, Telegram WebView и может устанавливаться как PWA.

## Игровые правила

- Асфальтовый квадрат делится на четыре квадрата. Один участник стоит в каждом секторе.
- Подача выполняется **по диагонали**: сначала мяч отскакивает в центральном квадрате, затем — в квадрате принимающего. Именно после **двух отскоков всего** принимающий может вернуть мяч ногой. Удар головой с лёта — исключение. Если подача отскакивает третий раз без отбивания, принимающий получает один пропущенный гол.
- Обычный удар: после первого отскока в своём квадрате разрешено отбивать ногой. Если мяч ударяется во второй раз без возврата, начисляется один пропущенный гол.
- Удар ногой до разрешённого отскока — один пропущенный самому бившему; удар головой допускается с лёта. Если удар головой приносит гол, получившему сразу начисляются **5 пропущенных** и он выбывает.
- Красный центральный квадрат после обычного удара — один пропущенный последнему бившему; центр во время начальной подачи — **обязательное исключение**, штраф не начисляется.
- При пяти пропущенных участник покидает игру, на его место встаёт следующий из очереди. В текущем автономном режиме, если в очереди нет человека, его заменяет бот. Если пользователь выбыл и нажал кнопку возвращения, он займёт **следующее** освободившееся место перед ботами.

## Что доступно сейчас

- Играбельный **одиночный матч**: человек в квадрате 1 + три бота, которые могут ошибаться, промахиваться и делать удары головой.
- Реакция на отскоки, сенсорные кнопки, выбор квадрата-цели, табло, автоматическая замена выбывшего, пауза/возобновление, новая партия, публикация ссылки.
- Адаптация к вертикальным экранам смартфонов; поддержка Telegram WebApp `ready`, `expand`, заголовка/фона и тактильной обратной связи, если они доступны. Для Telegram с поддержкой Fullscreen добавлена **кнопка полного экрана**, а кнопка «Поделиться» использует Telegram-диалог отправки ссылки. В обычном браузере эти элементы корректно скрываются или используют системный Share API.
- Никакой телеграм-аккаунт не требуется в браузерном режиме. В MVP нет регистрации, внешней аналитики и передачи персональных данных на сервер.
- Сохранение прогресса между посещениями **пока не предусмотрено**.

**Ограничение:** это **не реальный сетевой матч между четырьмя Telegram-аккаунтами**. GitHub Pages — статический хостинг, он не предоставляет авторитетный сервер или WebSocket-комнаты. Для PvP понадобится дополнительный backend, который будет проверять Telegram `initData` на сервере, управлять комнатами, очередью и таймингом отскоков. Нельзя доверять `initDataUnsafe` как авторизации. До появления такого сервера игра не должна заявляться как онлайн-PvP.

## Как открыть внутри Telegram

1. Веб-адрес игры (после успешного развёртывания GitHub Pages): `https://yugatn.github.io/YUGATNEO_GAME/four-square/`. Исходный код уже находится в репозитории. Доступность публичного URL рекомендуется проверить в браузере перед добавлением в бот.
2. В `@BotFather` выбери существующего бота (`/mybots`) → `Bot Settings` → `Menu Button` → настрой ссылку на этот HTTPS-адрес. Альтернатива — Mini App из профиля бота, если он поддерживается.
3. Открой чат с ботом в Telegram и нажми появившуюся кнопку. Откроется Telegram WebView со встроенной игрой. **Привязку к конкретному боту владелец выполняет в BotFather**; этот репозиторий не содержит его токена.
4. Обычная веб-ссылка открывается в любом браузере, а при запуске через кнопку Mini App Telegram предоставляет интерфейс WebApp.

Документация Telegram: https://core.telegram.org/bots/webapps


### Какую часть игры Telegram синхронизирует

Telegram лишь **открывает** веб-игру внутри своего клиента и предоставляет WebApp API; в этой версии на одном телефоне играет один человек с тремя ботами. Отправка ссылки друзьям запускает у них **отдельные** автономные партии, а не общий матч. Участники разных Telegram-аккаунтов пока не видят друг друга, пока не будет развёрнут отдельный серверный матчмейкинг.

**Не размещать** бот-токен в GitHub Pages, `app.mjs` или URL. Если появится сервер сетевой игры, подтверждение Telegram `initData` должно выполняться только на сервере по официальной схеме.

## Локальная проверка

```sh
python3 -m http.server 8765
# открыть http://localhost:8765/four-square/
node --test tests/four-square*.test.mjs
```

Для CI используется `.github/workflows/four-square-ci.yml`. Публикацией всего репозитория уже занимается `.github/workflows/pages.yml` при изменении `main`.
